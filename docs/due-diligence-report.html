Memory Exhaustion / DoS Risk while validating oversized constrained collections

Zod can hang or consume excessive memory when parsing adversarial or oversized payloads containing constrained collections. Remediate immediately via npm audit fix or upgrading Zod to the patched release.

MODERATE SEVERITY • GHSA-w74x-v6f9-j3xg Package: fast-uri (3.0.0-3.1.8 / 4.0.0-4.2.2)

URI Scheme Spoofing via percent-encoded decoding

Sub-dependency of Fastify/Ajv. Can lead to host confusion or improper path equivalence during URI normalization. Requires transitive dependency update.

LOW SEVERITY • GHSA-389g-gv7q-r4x8 Package: fastify (5.12.2 - 5.12.5)

Header validation bypass via case-sensitive propertyNames

Fastify can skip header validation rules when property casing does not match exact schema casings. Resolved in later patch versions.
